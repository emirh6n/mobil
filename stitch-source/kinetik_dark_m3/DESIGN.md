## Brand & Style

The design system establishes a high-performance, dark-mode-first environment tailored for holistic tracking: physical training, nutritional balance, daily habits, and productivity. Built on the structural integrity of Google Material Design 3 (M3), it projects discipline, vitality, and clinical focus.

### Tone & Personality
- **Focused & Utilitarian:** High visual clarity with distraction-free surfaces that prioritize metrics, data input speed, and progress assessment.
- **Electrifying Precision:** Deep charcoal and obsidian layers are activated by calibrated pistachio green accents (`#84E034`), instilling energy and immediate feedback on user action.
- **Ergonomic & Dependable:** Purpose-built for single-handed mobile operation with bottom-weighted touch targets, standard M3 touch targets (minimum 48x48dp), and thumb-zone optimization.

### Design Movement
**Corporate / Modern M3 Dark:** Strict adherence to Material Design 3 surface container hierarchies, tonal elevations, tonal state layers, and consistent rounded containers, balanced with athletic telemetry aesthetics.

## Colors

The palette operates on M3 tonal elevation in deep dark mode, utilizing systematic container shifts instead of pure black drop shadows to express depth.

### Core Roles
- **Primary (`#84E034`):** Electric Pistachio. Used for primary CTAs, active segmented buttons, completion highlights, progress indicators, and key metric readouts.
- **On-Primary (`#102E00`):** High-contrast deep forest green for text and glyphs resting on top of primary fills.
- **Primary Container (`#234B0B`):** Muted olive-forest backdrop for secondary active states, badge backgrounds, and non-destructive highlights.
- **On-Primary Container (`#B7FF80`):** Legible luminous pistachio for content on primary containers.
- **Secondary (`#20D5A0`):** Deep Emerald / Cyan-Teal. Reserved for secondary metrics (e.g., active distance, sensor telemetry, secondary progress rings).
- **Tertiary / Error (`#FF6B6B`):** Soft Coral. Communicates negative caloric balance, missed habit days, urgent deadlines, and destructive actions without inducing optical fatigue.

### Dark Surface Container Architecture
- **Surface (`#121316`):** Base canvas background, grounding viewports with zero optical flare.
- **Surface Container Lowest (`#0D0E10`):** Deep recessed wells for data cards and input field grooves.
- **Surface Container Low (`#16181C`):** Flat informational cards and group containers.
- **Surface Container (`#1A1C20`):** Default card baseline and interactive list modules.
- **Surface Container High (`#22252A`):** Floating navigation bars, active sheet backdrops, and elevated modal panels.
- **Surface Container Highest (`#2C3037`):** Elevated chips, segmented button unfocused tracks, and text input outlines.
- **Outline / Outline Variant (`#3E444D` / `#282B32`):** Low-contrast structural separators and hairline borders.

## Typography

The typography scale relies entirely on Inter, capitalizing on its tall x-height, neutral geometric forms, and high numerical legibility across dense biometric interfaces.

### Hierarchy & Application
- **Display & Large Headlines:** Used for hero KPIs (e.g., total calories burned, total workout time). Emphasized with bold weights and tight negative tracking.
- **Title Roles:** Card headers and section categories (`title-md` and `title-lg`), paired with pistachio accents (`#84E034`) to clearly segment dashboard areas.
- **Body Text:** Muted neutral light tones (`#D8DADF`) over surface containers ensure comfortable reading without high-contrast eye strain.
- **Label Roles:** Uppercase-compatible labels for data tags, tabular metadata, set/rep counters, and interactive navigation tokens. Full Turkish character set support with localized uppercase dotted "İ" and lowercase dotless "ı".

## Layout & Spacing

The layout is built upon an 8-point baseline grid with a 4-point subgrid for granular micro-spacing within metric chips and numeric counters.

### Mobile-First Ergonomics
- **Outer Canvas Margins:** `margin: 1rem` (16px) on mobile viewports, scaling to `margin-tablet: 2rem` (32px) on tablets.
- **Component Gutters:** `gutter: 1rem` (16px) vertical rhythm between primary dashboard cards; `gutter-sm: 0.5rem` (8px) between metric sub-items and calendar day cells.
- **Thumb Zone Design:** Primary input triggers, bottom sheets, and the floating navigation bar are pinned to the bottom 40% of the display for effortless single-handed thumb reaches. Top regions remain dedicated to historical context and passive date switches.

## Elevation & Depth

Visual hierarchy does not use blur-heavy drop shadows. Instead, it employs Material Design 3 surface-tonal elevation complemented by delicate ambient hairline borders.

### Elevation Levels
- **Level 0 (Canvas):** `#121316`. Base background layer.
- **Level 1 (Default Containers & Cards):** `#1A1C20` with a 1px border of `#282B32`. Provides crisp physical separation against dark backgrounds.
- **Level 2 (Active Cards & Segment Tracks):** `#22252A` with a 1px border of `#3E444D`.
- **Level 3 (Floating Bars & Modals):** `#262930` accompanied by a soft directional shadow: `0 8px 24px -4px rgba(0, 0, 0, 0.6)`.
- **Level 4 (Primary Action Glow):** Key focal points (such as primary FABs or active date chips) carry a subtle pistachio ambient bleed: `0 0 16px rgba(132, 224, 52, 0.25)`.

## Shapes

The system follows M3 roundedness principles with a base value of `2`:

### Geometry Rules
- **Base Components (`roundedness: 2` / 0.5rem - 8px):** Day cells in calendar grids, numeric input wells, and tight metric tags.
- **Medium Components (`rounded-lg` / 1rem - 16px):** Standard interactive input boxes, segment controllers, and list items.
- **Large Components (`rounded-xl` / 1.5rem - 24px):** Major dashboard modules, exercise progress cards, bottom sheets, and floating navigation bars.
- **Full Rounded / Capsule (`rounded-full`):** Filter chips, icon-only utility triggers, and standard floating action buttons.

## Components

### Buttons & Interactive Controls
- **Filled Primary Button:** Solid `#84E034` fill, `#102E00` bold text, rounded to 16px (`rounded-lg`), minimum height 48px. Features a bold icon prefix for instant actionability (e.g., lightning or plus icon).
- **Secondary / Tonal Button:** Surface container high (`#22252A`) with `#84E034` text and 1px border (`#3E444D`).
- **Segmented Control:** Enclosed track (`#1A1C20`) with 8px inner padding. The selected pill features an illuminated `#84E034` background with dark text, while unselected segments remain transparent with `#9EA2AA` typography.

### Cards & Telemetry Surfaces
- **Dashboard Metric Card:** Surface container base (`#1A1C20`), 20px padding, 16px corner radius (`rounded-lg`), bounded by a subtle 1px `#282B32` stroke. Section header uses uppercase or medium-weight typography in neon pistachio (`#84E034`).
- **Recessed Metric Wells:** Inside metric cards, numeric values sit within nested dark pods (`#0D0E10`) with `space-sm` padding to anchor telemetry data.

### Form Inputs & Text Fields
- **Exercise / Habit Input Fields:** Dark recessed surface (`#0D0E10`), 1px outline (`#2C3037`), transitioning to an energetic `#84E034` border on focus. Placeholder text uses low-emphasis `#686E78`.

### Calendar Matrix
- **Matrix Architecture:** 7-column flex grid with 8px internal gaps.
- **Unselected Days:** Deep surface containers (`#1A1C20`) with centered white/gray numbers.
- **Current / Selected Day:** Accent border (`#84E034`) or solid fill with indicator dot beneath the date. Missed or incomplete habit states marked with a subtle tertiary coral (`#FF6B6B`) baseline dot.

### Floating Bottom Navigation Bar
- Positioned floating 16px above the display bottom edge, utilizing `surface-container-high` (`#22252A`) with `rounded-xl` geometry and subtle 1px border. Active tabs are demarcated by an energetic pill backdrop (`#84E034`) surrounding the active icon.
